## 무엇을 하는가

매일 아침 **공공데이터포털** 의 3 개 API 에서 신규 공고를 자동 수집하고, 분야별로 균형 잡힌 5건을 큐레이션해 발행합니다.

| 출처 | 데이터 |
|---|---|
| 중소벤처기업부 (기업마당) | 중소기업 지원사업 공고 |
| 창업진흥원 (K-Startup) | 창업지원 사업공고 |
| 조달청 (나라장터) | 입찰 공고 |

## 분야

창업·사업화 / R&D·기술 / 자금·금융 / 판로·수출 / 인력·고용 / 시설·보육 / 인증·특허 / 입찰

## 콘텐츠 정책

- 모든 공고는 **공공데이터포털 원본** 을 그대로 인용하며, 클릭 시 원문 페이지로 이동합니다.
- 본 사이트의 큐레이션은 정보 안내용이며, **신청 가능 여부 / 자격 / 마감 / 변경 사항** 은 반드시 원문에서 직접 확인하셔야 합니다.
- AI 가 작성한 요약·매칭 사유에는 **[FACT] / [ESTIMATE] / [RECOMMENDATION]** 태그로 출처 명확성 표시.
- 외부 발송 / 광고성 게시는 하지 않습니다.

## 면책

본 사이트는 비영리 정보 큐레이션이며, 게시된 공고의 신청 결과 / 자격 충족 여부에 대해 책임지지 않습니다.
